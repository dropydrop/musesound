Plein écran : l'icône open_in_full doit masquer la sidebar et le header, ne laisser que le footer player en bas, en mode "cinéma". (Le vrai fullscreen API est trop contraignant, un mode "clean" suffit.)

FONCTIONNALITÉS À AJOUTER :

Mode répétition : 3 états (icône différente) :

Désactivé (gris) → passe à la suivante, fin de playlist → stop

Répétition une chanson (icône repeat_one) → rejoue la même

Répétition playlist (icône repeat) → revient à la première

Mode shuffle (lecture aléatoire) : icône shuffle. Quand activé, next() choisit un index aléatoire dans la playlist (ne pas modifier la playlist originale, juste l'ordre de lecture).
